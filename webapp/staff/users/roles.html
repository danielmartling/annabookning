User roles and permissions

This is a matrix explaining the different user roles in the system, and what the user of a certain role can do.

There are two roles: a user is either a staff member or a guest. Many actions require a permission along with the staff role.

db* = Can only be done in database.

✓ = permitted, ✗ = not permitted, - = not required.

Deletes are soft and can be restored (in db).
